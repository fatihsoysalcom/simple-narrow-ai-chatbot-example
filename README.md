# Simple Narrow AI Chatbot Example

This Python script demonstrates a "Narrow AI" system in the form of a simple rule-based chatbot. It is designed to respond to specific keywords and patterns, explicitly stating its limitations and lack of consciousness or general understanding. The example highlights how current AI systems excel at defined, specific tasks but do not possess the broader intelligence or sentience often depicted in science fiction.

## Language

`python`

## How to Run

Save the code as `chatbot.py`.
Open a terminal or command prompt in the same directory.
Run the script using: `python chatbot.py`
